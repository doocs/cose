在 Doocs MD 或 自托管编辑器中选择发布平台。

没有自托管编辑器？

也可使用官网编辑器

连接 DEV.to

  1. 登录 DEV.to，打开 Settings → Extensions。
  2. 在 DEV Community API Keys 输入名称（例如 COSE），点击 Generate API Key，复制生成的密钥。
  3. 把密钥粘贴到下面，点击「连接 DEV.to」，并允许 COSE 访问 dev.to。

密钥保存在此浏览器的扩展中，仅用于连接 DEV.to。

使用 md.doocs.org 时留空。使用自托管编辑器时，填入地址栏里的编辑器网址。

回到 MD 编辑器，打开「发布 → DEV.to」，点击「检查连接」。看到账号后即可勾选 DEV.to 创建草稿。
